# LaTeX Paper — Compilation Instructions

## Target venue
Computers & Geosciences (Elsevier)

## Requirements

### 1. Install LaTeX
macOS: install MacTeX (recommended — includes all required packages):
```
brew install --cask mactex
```
Or install TeX Live (minimal):
```
brew install texlive
```

### 2. Install elsarticle class
If using TeX Live minimal, run:
```
tlmgr install elsarticle
```
MacTeX includes `elsarticle.cls` by default.

Alternatively, download directly from CTAN:
https://ctan.org/pkg/elsarticle

### 3. Compile
From the `paper/latex/` directory:
```bash
latexmk -pdf main.tex
```
Or manually:
```bash
pdflatex main.tex
bibtex main
pdflatex main.tex
pdflatex main.tex
```
